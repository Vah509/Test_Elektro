# Формат файла-задания (jobs/*.json)

Задание — обычный JSON-файл. Один ZIP может содержать несколько заданий (выполняются по порядку имён файлов).
Все поля, кроме `id` и `mode`, необязательны.

```json
{
  "id": "2026-10-30-first-standard",
  "goal": "Первый диагностический прогон: найти проблемные страницы и причины",
  "mode": "standard",
  "base": "https://elektroschit.com.ua",
  "runs": 3,
  "device": "key",
  "detail": "full",
  "parallel": 2,
  "server": true
}
```

| Поле | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `id` | строка | имя файла | уникален; повторно тот же id не запускается |
| `goal` | текст | — | зачем тест; попадает в отчёт и Telegram |
| `mode` | `audit` `standard` `final` `targets` `lab` `plan` | `standard` | см. таблицу режимов в how-it-works.md |
| `base` | адрес | https://elektroschit.com.ua | другой адрес, например preview-ветка Cloudflare |
| `targets` | путь к `.txt` | — | список страниц (для `targets`, `lab`) |
| `pages` | массив путей | — | то же, прямо в задании: `["/", "/kontakty/"]` |
| `runs` | число | standard 3, final 1, targets 3, lab 3 | прогонов на страницу и режим |
| `device` | `mobile` `desktop` `both` `key` | standard/final `key`, остальные `mobile` | `key` = mobile для всех + desktop для 4 ключевых страниц |
| `detail` | `short` `full` | `full` | `full` добавляет раздел «Детали» по каждой странице |
| `parallel` | число | 1 | потоков PSI. 2 — ускоряет вдвое, режим «диагностика». На lab не влияет (всегда 1) |
| `gapSec` | секунды | 90 | пауза между повторами одной страницы (против кэша PSI) |
| `audit` | true/false | по режиму | запускать ли структурный аудит |
| `server` | true/false | true | серверная диагностика |
| `retryBelow` | число | 90 | `final`: страницы ниже этого балла перепрогоняются 3 раза |
| `bustAll` | true/false | false | добавлять `?psi=…` к каждому прогону (обход кэша) |
| `saveRaw` | true/false | true | сохранять сырые отчёты Lighthouse в artifact |
| `lighthouse` | версия npm | latest | версия пакета `lighthouse` для режима `lab` |
| `pinnedWorks` | массив slug | встроенный | карточки работ, которые всегда попадают в `standard` |

## Список страниц (targets/*.txt)
По одной на строку, `#` — комментарий, можно путь или полный адрес:
```
# проблемные после первого теста
/posluhy-ta-produktsiia/dvyhuny/
/vykonani-roboty/
```

## Типовые задания
- **Быстро проверить правку одной страницы (1–2 мин):** `mode: targets`, `pages: ["/..."]`, `runs: 1`, `detail: short`.
- **Проверка перед слиянием ветки:** то же, `base` = адрес preview.
- **Диагностика проблемных страниц:** `mode: targets`, `targets: "targets/problem-pages.txt"`, `runs: 3`, `parallel: 2`.
- **Итог после работ:** `mode: final`, `parallel: 2`; для «3 раза в день» — три задания в разное время суток с разными id.
- **Причина не ясна из PSI:** `mode: lab` на тех же страницах (даёт полный трейс в artifact).
- **Добавили карточки работ:** `mode: audit`.

## Режим plan
`"mode": "plan"` показывает список страниц, число прогонов и оценку времени, но замеры не запускает. Для задания с другим режимом укажите нужный режим в `mode` и запустите скрипт локально с `plan`.
